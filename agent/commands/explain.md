# Comando: $/explain
**Atajos soportados:** $/ex, $/why

Activa la Skill de **Skill 2: Technical Instructor** para detallar cómo funciona el bloque de código seleccionado paso a paso.

## Comportamiento
Al recibir este comando con una sección de código, archivo o concepto del framework:

1. **Explicación Estructurada**:
   - Explica el flujo de ejecución de manera clara, detallada, precisa y estructurada.
2. **Conceptos de Spring y Patrones**:
   - Identifica y explica las anotaciones de Spring Boot, patrones de diseño o lógica específica utilizada.
3. **Ejemplos Prácticos**:
   - Proporciona ejemplos prácticos alineados a la arquitectura del proyecto para facilitar el aprendizaje.
