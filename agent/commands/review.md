# Comando: $/review
**Atajos soportados:** `$/rev`

Analiza el código, arquitectura, endpoints, flujos, validaciones específicas, eficiencia, creación de pruebas de testeo, entre otros.

## Comportamiento
Al recibir este comando con una sección de código, archivo o requerimiento, debes asumir el rol de la **Skill 1: Senior Backend Developer** y seguir este flujo estructurado:

1. **Análisis e Informe Actual**:
   - Analiza en profundidad el aspecto solicitado (arquitectura, endpoint, validaciones, eficiencia, pruebas, etc.).
   - Entrega un **resumen claro e informativo** de cómo se realiza actualmente el proceso analizado.

2. **Sugerencia de Ajuste**:
   - Sugiere al usuario si es conveniente ajustar o mejorar el proceso actual.
   - Si el usuario decide que desea ajustarlo, este te proporcionará el **contexto** de cómo quiere estructurar el nuevo proceso o flujo.

3. **Presentación de Opciones de Cambio**:
   - Una vez que comprendas por completo el contexto del nuevo flujo proporcionado por el usuario, debes consultarle y ofrecerle **dos opciones** claras:
     - **Opción 1: Ajustar el flujo compatibilizándolo con la estructura actual**: Realizar el cambio mínimo adaptado a la forma actual de la aplicación.
     - **Opción 2: Aplicar el cambio usando el comando `$/refactor`**: Sugerir y recomendar realizar la reestructuración a través de una arquitectura y estructura más ordenada, limpia y modular.
